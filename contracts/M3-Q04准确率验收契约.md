## 3. 判定规则（**已批准 v1.0，2026-09-24**）

> 全部为**确定性规则**，无 LLM/网络。阈值已随 §7 获用户 2026-09-24 批准，落在 `tools/q04_grader.py` 常量。

### 3.1 判定顺序（短路）

```
空假设 / 空白 / None            -> FAIL(EMPTY)
关键语义槽位违规 > 0            -> FAIL(KEY_SLOT_*)        # 即使只 1 处
整句重写 (REWRITE)              -> FAIL(REWRITE)
局部修正 > 2 处                 -> FAIL(TOO_MANY_CORRECTIONS)
大段/重排歧义                   -> NEEDS_REVIEW(REORDER / LARGE_DIFF)   # 不计 PASS
否则                            -> PASS
```

标点/空格差异**单独计数**（`punct_space_diff`），**不改变 status**（§3.4）。

### 3.2 局部修正计数

内容词元（代码/路径/数字词元 + 单个汉字）做 `difflib.SequenceMatcher` 对齐；**非 equal 的 opcode 块数** = 局部修正处数
（同一词或连续片段的一次替换/增/删合并为 1 处）。标点与空白不进入该对齐。

### 3.3 关键语义槽位（**已批准 2026-09-24，选从严 A**）

- **声明槽位** `slots`：`名 -> 必须出现在假设中的期望子串`；未命中 → `KEY_SLOT_<名>`。
- **自动兜底（从严生效）**：
  - 否定字符集合（`不没别无勿莫非未`）在参考/假设间**出现计数不同** → `KEY_SLOT_NEGATION`；
  - 数字词元序列（含小数点、负号）不同 → `KEY_SLOT_NUMBER`；
  - 含路径分隔符的代码词元序列不同 → `KEY_SLOT_PATH`。
- **严格点（已批准）**：**任何**数字序列差异即判"关键数字错误"；**任何**否定字符增减即判"否定反转"；
  **任何**含路径分隔符词元序列差异即判"路径错误"；**自动兜底从严生效**（不降级为 REVIEW）。

### 3.4 归一化与标点/空格

- **归一化**：`unicodedata.normalize("NFKC", …)` 折叠全角→半角（含全角数字/标点）；**不改汉字**；不删任何分隔符。
- **代码词元保护**：形如 `[A-Za-z0-9_][A-Za-z0-9_./\\:+=-]*` 视作整体，保护 `. / \ : + = - _` 与版本点 → `1.5`≠`15`、`a/b`≠`ab`、`v2.10.1` 不被切碎。
- **标点/空格（已批准 2026-09-24，选 A）**：单独流与空白模式比较，差异计入 `punct_space_diff`，**不占 ≤2 额度、不改变 status**
  （即"标点/空格差异不导致不合格"，golden-02）。

### 3.5 大段/重写阈值（**已批准 2026-09-24**）

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `MAX_LOCAL_CORRECTIONS` | 2 | 已批准（≤2 处） |
| `LARGE_DIFF_SPAN` | 4 | 单个差异块跨度 ≥4 词元 → 不算"轻微修正" → NEEDS_REVIEW |
| `REWRITE_SIMILARITY` | 0.5 | 相似度 <0.5 且大块主导 → REWRITE FAIL |
| `REWRITE_CHANGED_FRACTION` | 0.5 | 改动占比 >0.5 且大块主导 → REWRITE FAIL |
| `REVIEW_BLOCK_FRACTION` | 0.25 | "大块主导"判据：单块占比 >25% |
| `REQUIRED_SAMPLES` / `MIN_PASS` | **15 / 14** | 2026-09-24 修订（原 30/27）；90% |

### 3.6 整卷判定

`pass_count >= 14` → `overall PASS`；`total != 15` 时报告显式标注 **"不能作为 Q04 验收依据"**（分母完整性护栏）。

## 5. 语料冻结与采集（"不得看到模型输出后改参考"的机械执行）

**草稿清单 schema**（顶层**仅** `{"samples":[...]}`，**恰 15 条**；字段名与含义）：

| 字段 | 类型 | 必填约束 |
| --- | --- | --- |
| `id` | str | 非空白、**不得重复** |
| `wav` | str | 非空白（录音来源路径） |
| `wav_sha256` | str | **64 位小写十六进制**（录音哈希，锚定音频） |
| `speaker_authorized` | bool | 必须 **true**（说话人授权） |
| `language` | str | 非空白 |
| `technical_words` | str[] | 元素非空白；可为空列表 |
| `duration_s` | number | 正数 |
| `ambient_noise` | str | 非空白（环境噪声） |
| `device_distance_m` | number | 正数（设备距离） |
| `reference_text` | str | 非空白（**人工参考文本**，冻结前定稿） |
| `key_slots` | object | 须含 `negation`/`action_object`/`number`/`file_path` 四个非空白槽位（可加额外槽） |
| `acceptable_equivalents` | str[] | 元素非空白；可为空列表。**已登记"有意不自动放行"**，仅作人工复核参考（见 §7 Q04D-1） |
| `audio_environment` | str | 非空白 |

**命令**：

```bash
python tools/q04_corpus.py freeze <draft.json> <frozen.json>   # 校验并冻结（拒绝覆盖、拒绝≠15条/缺字段）
python tools/q04_corpus.py verify <frozen.json>                # 重算内容哈希比对（篡改即非零退出）
```

**哈希口径（有意选择）**：`content_hash = sha256(canonical_json(冻结内容))`，canonical = `sort_keys=True`、紧凑分隔符、`ensure_ascii=False`；
`content_hash` 字段不参与。样本**顺序参与**哈希（清单顺序即语义）→ 改参考文本/改 wav 哈希/增删重排/改任一字段**必被检出**；
键序与空白排版差异不影响（哈希锚定内容而非排版，重复 verify 幂等）。

**采集**：说话人授权、语言、技术词、时长、环境噪声、设备距离、**人工参考文本**须在**运行前**逐条落定；
参考文本一旦冻结不得在看到模型输出后回改（工具层面拒绝覆盖）。`reference_text`/`wav_sha256` 由**用户/记录者**提供，工具**不生成**。
采集台账模板见 [Q04 语料采集与冻结清单-模板](../tools/Q04语料采集与冻结清单-模板.md)。

## 6. 明确不做

- **不做** LLM 自评/自动润色作为裁判；**不做**自动提交。
- **不因**"标点另计"把 `1.5` 与 `15` 视为相同；**不删**路径分隔符/小数点/负号/版本点/代码标识。
- **不剔除**空结果/失败句；**不**把 NEEDS_REVIEW 记 PASS；**不**把大段 diff/整句替换算作 1 处轻微修正。
- 工具**不含也不生成**任何真实语料内容；不保存用户日常录音。
- 本文件**不覆盖** TX-07（20s 超时起点，归 M1）与持续/冷启动/重连场景（归 Q05）。
- **`acceptable_equivalents` 不自动放行**（有意不提供该自动化，见 §7 Q04D-1）。
