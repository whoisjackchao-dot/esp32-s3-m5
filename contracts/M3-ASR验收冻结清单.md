## 3. 错误分类（已在 M1 契约冻结，M3 复用）

| 现象 | 处理 |
| --- | --- |
| 401 / 403 / 429(1113 欠费、1302/1305 限流、1311/1315 套餐) | 分类提示，**不自动重试** |
| 400(1210/1211/1213/1214) | 参数/模型 ID/格式错误 |
| 5xx / 连接超时（curl 28） | 先查调用记录再决定重试，避免重复计费 |
| 200 但 `text` 为空 | 不追加；不直接提交空文本 |
| 识别成功但术语错误 | 用通用热词；按 15 条验收（2026-09-24 修订），**不用聊天模型偷偷改写** |

## 4. 数据最小化（ASR-05 硬约束）

出站请求**不得**包含：项目 title、文件路径、sessionID、已有草稿、用户名、设备 MAC。仅含：WAV、模型名、通用热词、随机 `request_id`。
