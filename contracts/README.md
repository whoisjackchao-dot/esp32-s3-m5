## 规则

- 每个冻结文件必须**可测试**：每条取值能对应到至少一个测试 ID。
- 冻结变更须：更新版本 → 同步契约测试与受影响回归 → 记录 ADR → 不保留未发布版本的兼容包袱。
- 标「待批准」的工程取值在用户确认前按提案实现且可配置，**不得**在验收文档中当作已批准值。
