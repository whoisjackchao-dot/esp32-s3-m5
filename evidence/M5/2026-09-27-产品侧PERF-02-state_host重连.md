# 产品侧 PERF-02 — `state_host` 自身重连 + STATE 复原（M5）证据

> 日期：2026-09-27。用例：PERF-02 的**产品侧**（链路版见 [2026-09-27-PERF-02断线恢复.md](./2026-09-27-PERF-02断线恢复.md)）。
> 结论：**20/20 次 ≤15s（worst 10.032s）→ PASS**；但 Δ 稳定在 **~10.0s 平台**（值得登记，见 §3）。

## 1. 机制
- 给 `state_host` 加**受限自断链测试模式**：env **`STICKS3_HOST_DROP_TEST=N`**（默认关；`state_host.cpp`）。
- 每轮：一次成功 STATE 推送后，写 **`0x7F`** 令**设备主动断链**（`t0`）→ host 在下次推送失败时**自行重连**（BLE 重连 + 重订阅 SSE）→ 下一次 STATE 推送成功（`t1`）→ `Δ=t1−t0`。
- 中心＝**产品 `state_host` 本身**（真实桥接 OpenCode `11523` + 真实设备）。

## 2. 结果（2026-09-27）
- **20/20 次 Δ ≤ 15s**；Δ：min **6797ms**、median **10015ms**、max **10032ms**。
- `VERDICT=PASS`（门槛 ≥19/20）。
- 逐条(ms)：6797, 10015, 10016, 10015, 9969, 10016, 10031, 9953, 10031, 10016, 10016, 10015, 10032, 9953, 10015, 10032, 10015, 9969, 10016, 10015。

## 3. 观察（重点）
- Δ 几乎恒为 **~10.0s**（远大于链路恢复的 <2s）→ **`state_host` 重连路径引入 ~8s 固定延迟**。**仍 <15s 门槛**，但**裕度薄**。
- 首次 6797ms 略快、其余稳定 ~10.0s → 疑为某处**固定超时**（host 断链检测/重连节奏，如 WinHttp/SSE 或重连 sleep）。**待定位**（M5 后可优化）。
- **不构成 PERF-02 失败**（20/20 ≤15s），但登记为**性能观察**。

## 4. 边界 / 待办
- 测试模式 **env 门控、默认关**；**属测试钩子**，M6 前须**移除或登记**（同固件 `0x7F`）。
- "加密"由 bond 保证（未独立探测）；"STATE 复原"以**成功推送**为准。
- 建议：定位 ~10s 固定延迟来源（优化项）。

## 5. 合并结论（PERF-02 两侧）
| 侧 | 中心 | 结果 | worst |
| --- | --- | --- | --- |

| **产品** | **state_host** | **20/20 ≤15s** | **10.032s** |

→ **PERF-02 达标**（两侧均 ≥19/20 ≤15s）。
