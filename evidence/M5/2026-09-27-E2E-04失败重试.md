# E2E-04 — 失败 → 重试 →（查询）（M5）证据

> 日期：2026-09-27。用例：**E2E-04（部分）**。
> 结论：**PASS（失败→手动重试→计数 部分）**；**ACK 丢失 → 查询 未做**（见 §4）。

## 1. 方法
- **ASR 失败注入**：`state_host` 的 ASR 指向 `tests/tools/mock-asr`（`POST /__mock/config {scenario:http_500}`）。
- 中心＝`state_host`（连真实桥接 + 设备，`STICKS3_ASR_HOST/PORT` 覆盖 ASR）。

## 2. 结果（2026-09-27）
- 设备录音 `rec=105` → `audio held (8089 B) can_recognize=1` → **`voice: ASR class 5 (no text)`**（失败）→ **无 append**。
- `GET /v1/retry/status` → `{"canRecognize":true,"canAppend":false,"hasAudio":true,"hasText":false,"status":4}`。
- **手动重试**（等价托盘：`POST /v1/retry/recognize`）→ **HTTP 202 accepted** → host 再次 **`voice: ASR class 5 (no text)`**（再次失败）→ 仍 `canRecognize:true / status:4`。
- **ASR 调用次数 = 2**（1 自动 + 1 手动）= 人工尝试次数；**草稿 append = 0 次**（均失败）；**TTL 内仍可重试**。

## 3. 判据
| 断言 | 结果 |
| --- | --- |
| API 调用数符合人工次数 | ✅ 2 = 1 + 1 |
| 草稿只追加一次 | ✅ 0 次（全失败，未超 1） |
| TTL / 日志符合约束 | ✅ 5min 窗口内可重试 |
| 失败保留、不剔除 | ✅ 保留 held 音频 |
| 未知不造值 | ✅ 失败不输出伪文本 |

## 4. 边界（未覆盖）
