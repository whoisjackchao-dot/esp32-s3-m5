> 日期：2026-09-25（续）。范围：**S4.2 生产 host 的验证增量**——把 `ble_client` 的 BR-03 状态源确认为插件桥接的 **真实快照**（而非 binding 回退），并端到端打通「真实快照 → `state_merge` → `s3p_state_encode` → BLE → 设备」。

## 4. 判据核对

| 判据 | 结果 |
| --- | --- |
| 状态源为**真实快照**（非 binding 回退） | ✅ `src=snapshot` |
| 快照字段映射正确（status/flags/revision） | ✅ 下发 `status=2 flags=0x39 rev=1` |
| 设备侧解码与下发**一致** | ✅ 设备回显 `status=2 flags=0x39 rev=1` |
| 富载荷（TLV 文本区）可用 | ✅ `len=71`（23 固定 + title/model TLV）；未触发 ATT error |
| 会话完整性未回归 | ✅ 500 帧、`COMPLETE`、FNV-1a 独立复算一致 |

`flags=0x39` = bit0 `canAppend` + bit3 `hasTitle` + bit4 `hasModel` + bit5 `hasUsage`（此刻无 project、无工具失败、无子任务繁忙）。

- 仅证明「真实快照 → 合并 → BLE → 设备」这一跳；**不**代表常驻/托盘形态的**生产 host** 已交付。
