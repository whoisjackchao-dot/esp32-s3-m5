# 证据：S4.3 UI 布局校准（外壳遮挡下移 + 电量常驻 + 页脚防裁）

> 日期：2026-09-26。范围：S4.3 三页 UI 的真机多轮目视校准（用户逐条裁定）。
> 本文件是证据记录。

## 1. 变更（按用户裁定顺序）

| # | 裁定 | 实现 |
| --- | --- | --- |
| 1 | 电量**三页常驻** | `BAT` 绘制从 `page == 0` 分支**移到 if/else 之外的公共区** |
| 2 | `BAT` 保持 16px，**百分比/充电改 8px** | `draw_str("BAT", …, scale=2)` + `draw_str(pct, …, scale=1)` |
| 3 | 电量**百分比/充电改白色** | 值用 `C_WHITE`（`BAT` 保留蓝 `#3399FF`） |
| 4 | **整体文本下移**（顶部缺字＝**打印外壳遮挡**，非显示缺陷） | 新增 `#define Y_SHIFT 8`；在文本原语 `draw_char8` / `draw_char_px` **入口**统一 `y += Y_SHIFT` |
| 5 | 页脚 `1/3` **不得被底部裁切** | 锚点改 `DISP_H - 12 - Y_SHIFT` |

## 2. 关键判定：顶部「缺字」的根因

用户先观察第 1 页紫色 `STATUS` 显示不全，**首轮按显示缺陷处理**（标题 y 2→8、`STALE` 22→26）。随后用户判定实为**打印保护壳遮挡屏幕顶部** → 改为**全屏文本整体下移**（`Y_SHIFT`），并把先前的标题/`STALE` 单独下移**回退**，统一走全局偏移（**避免双重偏移**）。

- 该判定意味着**不改面板初始化**（`gap(52,40)` 与 `invert` 不变），只调整内容 y 基准。

## 3. 布局审计（`Y_SHIFT=8` 后逐元素核对）

| 页 | 最低元素 | 下移后 y 区间 | 越界 |
| --- | --- | --- | --- |
| 0 STATUS | REC(16) / BAT(16) / 值(8) | 194..209 / 212..227 / 216..223 | 否 |
| 1 TASK | TODO 值(16) | 178..193 | 否 |
| 2 USAGE | COST 值(16) | 148..163 | 否 |
| 公共 | 页脚(8) | **228..235**（补偿后） | 否 |

- **发现并修复**：页脚原锚点 `DISP_H-12`(=228) 加 `Y_SHIFT` 后为 **236..243**，**超出 240 面板** → 字形仅画到 236..239（**半截**）。补偿为 `DISP_H-12-Y_SHIFT`(=220) → 228..235 ✅ 完整。
- `draw_char8` / `draw_char_px` 均有 `py < DISP_H` 边界判断，越界像素**丢弃**，无帧缓冲越界写。

- 模拟器为**静态样例**（电量固定 `87%`、无 REC/STALE/多状态），仅用于布局目视，**不作为功能证据**。

- 未做多分辨率/旋转适配（**竖屏固定**，用户要求不变）。
