# 采音时基诊断（2026-09-23，进行中）

> 状态：**根因已定位，修复未验证**。所有数字均为本次实测。
> 影响：设备录音"变声/变速/听不清"→ ASR 幻觉（英文乱句）→ 纵切第三步失败。

## 1. 现象

M3 纵切实测：设备录 30 秒 → 解码 WAV → 智谱 ASR 返回**流畅但完全不相关的英文**
（用户实际说中文）。用户盲听 WAV 判定："噪音，变声，变速，听不清楚"。

## 2. 排除法（逐层验证，全部通过）

| 层 | 验证方法 | 结果 |
| --- | --- | --- |
| Opus 参数 | 解析 .s3pcap 首包 TOC | ✅ SILK / WB(16k) / 60ms / 单声道，包 110~164B 符合语音 |
| 解码链 | 440Hz 合成正弦 → 编码 → 解码 → FFT | ✅ 解出 **439Hz**（正确） |
| 数据完整性 | 设备 END.summary vs 主机独立 FNV-1a | ✅ 逐字节一致 |
| I2S 时钟（驱动侧） | `i2s_channel_get_info()` | ✅ sclk=160MHz **mclk=4096000Hz bclk=512000Hz**（与设计一致） |
| 引脚时钟（PCNT） | PCNT 计 MCLK/BCLK/WS | ❌ 方案不可行（引脚已由 I2S 占用，无法计数） |

## 3. 决定性测量：已知频率端到端测试

**方法**：PC 播放 1kHz 纯音（`C:\Temp\tone_1k.wav`，12s）→ 设备录音 → 解码 → FFT 找峰。

| 测试音 | 录音中出现 | 比值 |
| --- | --- | --- |
| 1000 Hz | **389 Hz** | 0.389 |

**推导**：设备实际采样率 R 满足 `1000 × 16000 / R = 389` → **R ≈ 40.96 kHz**。

**机制**：40.96k = MCLK 4.096MHz ÷ 100；而驱动意图为 MCLK ÷ 256 = 16k。
比值 16k/40.96k = **0.3906**，与观测 0.389 吻合 → **ES8311 实际分频 ÷100，而整条链按 ÷256 解释** → 时间拉伸 **2.56 倍**。

**旁证（会话耗时）**：`END samples=480000 耗时=19732ms`。若真 16kHz，480000 样本应耗时 30s；实测 19.7s（含编码/通知开销）→ 采样确实快于 16k，与 40.96k 自洽（11.7s 采集 + ~8s 开销）。

## 4. 辅助观察

- 原始 PCM 过零率（讲话期间）：**928/s**（参考录音 1803/s，比值 0.51）——方向一致但**不能单独作为速率证据**（ZCR 受内容影响大，故改用已知频率法）
- 启动自检偶见满幅样本（min=-32768/max=32767）：疑似瞬态饱和，**待时基修复后重新评估**（勿与本次根因混淆）
