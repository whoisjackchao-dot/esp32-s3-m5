## 2. 全链判读（`voice_slice.ps1` 三步）

### 2.1 BLE 采音（30s）

| 项 | 实测 |
| --- | --- |
| scan / paired | found；Just Works bond active |
| connect | link connected |
| service discover | mode=1 报 `0x80070016`，随后 characteristics audio/ctrl/event 齐备（判 PASS） |
| CCCD | written（encrypted link） |
| READY | 写入 `1001f700` |
| 录音 | recID=3，frames=500，rate=16000 |
| END | totalFrames=500 totalSamples=480000 summary=`0xa1ffa3c3` rc=0 |
| reasm | rc=0 state=COMPLETE frames=500 bytes=**77509** |
| **独立 FNV-1a** | `a1ffa3c3 == a1ffa3c3`（与设备 END.summary 一致） |
| 状态回写 | `write STATE bitmap=0x00`（bridge absent → 设备侧 UNKNOWN，见 §7.4） |

### 2.2 Opus 解码 → WAV

- 500 frames → 1440000 samples @48kHz = **30.00s**

## 3. 独立校验：三处字节级自洽

`.s3pcap` 容器格式为 `12字节文件头 + N×(6字节帧头 + 载荷)`（见 `tools/decode_capture.py`）。

| 校验 | 计算 | 实测 | 一致 |
| --- | --- | --- | --- |
| 容器分解 | 12 + 500×6 + 77509 | = **80521** = rec_3.s3pcap 实际大小 | ✓ |
| WAV 大小 | 44 + 1440000×2（16bit mono） | = **2880044** = rec_3.wav 实际大小 | ✓ |
| 时长 | 500 × 60ms | = **30s** = 解码实测 30.00s | ✓ |
| 端到端完整性 | 设备 END.summary vs 主机独立 FNV-1a | `a1ffa3c3` == `a1ffa3c3` | ✓ |

1. **Key 供给未按计划**：`voice_slice.ps1` 仍用 `Read-Host` 手工输入，未走 C11 凭据管理器（`asr_cred_tool`）。属计划/实现登记差异，未阻塞纵切，待修。
