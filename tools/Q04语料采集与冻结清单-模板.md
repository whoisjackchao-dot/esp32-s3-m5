# Q04 语料采集与冻结清单（模板，供逐条审阅/填写）

> 用途：把 [M3-Q04 契约 §5](../contracts/M3-Q04准确率验收契约.md) 的语料冻结要求，落成**可逐条填写的台账**。
> **数量已定 15 条**（2026-09-24 由 30 修订）。**本模板不生成、也不预填任何真实语料内容**（"未批准不当作事实"）；15 条口述内容与参考文本**由你定稿**。
> 冻结工具：`tools/q04_corpus.py`（`freeze` / `verify`）。冻结后**任何改动都会被哈希检出**。

## 1. 执行步骤

1. 先在下表按 **Q04A-4 覆盖分布**填 15 条口述内容（**参考文本草稿**，即"人工参考文本"）。
2. 逐条录音 → 落盘 `captures/q04/<id>.wav`。
3. 计算每条 wav 的 `sha256`（见 §5）。
4. 按 §4 骨架生成草稿 JSON（顶层**仅** `{"samples":[...]}`，**恰 15 条**）。
5. `python tools/q04_corpus.py freeze <draft.json> <frozen.json>`（拒绝≠15/缺字段/覆盖）。
6. `python tools/q04_corpus.py verify <frozen.json>`（此后任何改动→非零退出）。

## 4. 草稿 JSON 骨架（占位符，**勿照抄为真实语料**）

```json
{
  "samples": [
    {
      "id": "q4-01",
      "wav": "captures/q04/q4-01.wav",
      "wav_sha256": "<64位小写十六进制，见下命令>",
      "speaker_authorized": true,
      "language": "zh-CN",
      "technical_words": [],
      "duration_s": 0.0,
      "ambient_noise": "<环境噪声描述>",
      "device_distance_m": 0.0,
      "reference_text": "<你定稿的人工参考文本>",
      "key_slots": {
        "negation": "无",
        "action_object": "<或 无>",
        "number": "<或 无>",
        "file_path": "<或 无>"
      },
      "acceptable_equivalents": [],
      "audio_environment": "<安静室内 / 工位 等>"
    }
  ]
}
```

**字段硬约束（`freeze` 会校验，任一不满足即拒绝并逐条报错）**：

| 字段 | 约束 |
| --- | --- |
| 顶层 | **仅** `samples`；**恰 15 条**；`id` 不得重复 |
| `id` `wav` `language` `reference_text` `ambient_noise` `audio_environment` | 非空白字符串 |
| `wav_sha256` | **64 位小写十六进制** |
| `speaker_authorized` | 布尔 **true** |
| `duration_s` `device_distance_m` | 正数 |
| `technical_words` `acceptable_equivalents` | 字符串数组（元素非空白；可为空数组） |
| `key_slots` | 须含 `negation` / `action_object` / `number` / `file_path` 四个**非空**槽位（可加额外槽位） |

## 5. 常用命令

**计算 wav 哈希**：

```bash
# Windows PowerShell
(Get-FileHash -Algorithm SHA256 "captures\q04\q4-01.wav").Hash.ToLower()
# 或 WSL / Python
python3 -c "import hashlib,sys;print(hashlib.sha256(open(sys.argv[1],'rb').read()).hexdigest())" captures/q04/q4-01.wav
```

**冻结与校验**：

```bash
python tools/q04_corpus.py freeze <draft.json> <frozen.json>   # 退出码 0=成功 / 1=拒绝
python tools/q04_corpus.py verify <frozen.json>                # 退出码 0=一致 / 1=被改动
```

- **边界**：本清单**不含**真实语料；`freeze` 成功仅证明"15 条清单合法且已冻结"，**不证明任何识别准确率**。
- **已实现**：冻结语料 `key_slots` 与评分器 `slots` 已接线 → `tools/q04_adapter.py`（Q04D-2，2026-09-24；运行前先校验冻结哈希）。
