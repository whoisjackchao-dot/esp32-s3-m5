## 受控 ASR 服务规格（TEST-API-01，M3 实现）

**目的**：让自动化测试驱动真实主机 ASR 路径而**不产生云费用**，并检查实际出站请求字段。

| 能力 | 要求 |
| --- | --- |
| 正常 | 返回 `200` + 指定 `text` |
| 空文本 | 返回 `200` + `text: ""` |
| 无效 JSON | 返回畸形 body |
| 错误码 | `401` / `429` / `5xx` 可注入 |
| 延迟 | 可注入延迟以测 `APPEND_DEADLINE` / 20 秒超时 |
| 请求检查 | 记录实际 multipart 字段、模型名、路径、是否含禁用字段（ASR-05） |
| 边界 | **不得**进入生产网络面；**不得**作为识别质量证据（只证明 adapter） |

## 规则

- 测试隔离真实项目、真实凭据、真实录音（测试矩阵 §1）。
- 不得批量勾选 PASS；T 类附 RED/GREEN 证据，C/H 附真实边界证据。
- 黄金向量独立计算，不从待测 serializer 生成期望值。
- 真实云测试需独立授权与费用上限，不进普通 CI。
